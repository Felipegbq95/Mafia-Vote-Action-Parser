Mafia Vote Counter

Paste your game log, get an instant vote tally & a ready-to-post message.

Paste your forum's "Print" thread view (the format with Title: / Post by: Name on <date> per post). We auto-detect the current day, the alive player roster, and the majority threshold from your game master's posts, and tally each player's most recent VOTE: Name / UNVOTE. Quoted old votes are ignored. Plain Username: message logs also work. This box keeps bold formatting when you paste, and if your game only counts bolded votes, we only count bolded ones too.

One player per line: RosterName: nickname1, nickname2. Use this when someone votes using a name unrelated to their roster/forum name (e.g. "Axatar" also goes by "Joe"). Saved in this browser so you don't have to re-enter it every game.
